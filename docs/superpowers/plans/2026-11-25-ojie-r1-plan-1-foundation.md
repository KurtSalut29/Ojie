# Ojie Release 1 · Plan 1: App Foundation and Design System Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the empty app into Ojie's foundation: design tokens, bundled fonts, core components, English/Filipino text, Riverpod + go_router with a signed-in guard, and the student 4-tab shell, all proven on Kurt's phone.

**Architecture:** Design tokens live in `ThemeExtension`s (`OjieColors`, `OjieTypography`) plus constant classes for spacing, radius, motion and sizes. Core widgets in `lib/core/widgets/` use only tokens. Riverpod (no code generation) provides the Supabase client, the PowerSync database and auth state; go_router builds a `StatefulShellRoute` for the 4 student tabs and redirects signed-out users to sign in.

**Tech Stack:** Flutter 3.50 (stable), `material_ui` 1.11, `flutter_riverpod` 3.5, `go_router` 18.1, `lucide_icons_flutter` 4.0, `flutter_localizations` + `intl` (gen-l10n), PowerSync 2.6, supabase_flutter 2.18.

**Spec:** `docs/superpowers/specs/2026-11-25-ojie-release-1-design.md` (sections 3, 4, 5, 12, 13 and build-order step 1). Quality rules: `docs/quality/ojie-quality-bar.md`.

## Global Constraints

- Import Material widgets from `package:material_ui/material_ui.dart`, never `package:flutter/material.dart` (deprecated in Flutter 3.47+).
- Feature and widget code uses tokens only: no raw hex colors, no magic font sizes, no hard-coded spacing outside `OjieSpace`/`OjieRadius`/`OjieSize`.
- Fonts: **Fraunces** (SOFT 100, weight 600) for titles and Ojie's voice; **Plus Jakarta Sans** for everything else and all numbers (tabular figures). Bundled in the app.
- Icons: **Lucide** (`lucide_icons_flutter`) only. No emoji in buttons, labels, tags or navigation.
- All text colors meet WCAG AA: 4.5:1 for text, 3:1 for input borders.
- Touch targets at least 48 × 48 dp. Animations respect `MediaQuery.disableAnimationsOf`.
- Student tabs, in order: **Ngayon**, **Journal**, **Reqs**, **Journey** (icons `house`, `notebookPen`, `listChecks`, `map`). Selected tab: `primaryText` icon and label on a `primarySoft` pill.
- Languages: English (`en`) and Filipino (`fil`).
- The root `.env` holds only public values; run the app with `flutter run --dart-define-from-file=../.env` from `app/`.
- Every task ends with `flutter analyze` clean, tests passing, and `dart format` applied.

`app/lib/core/theme/contrast.dart`:
```dart
import 'dart:math' as math;

import 'package:material_ui/material_ui.dart';

/// WCAG 2.x contrast ratio between two opaque colors (1.0 to 21.0).
double contrastRatio(Color a, Color b) {
  final la = _relativeLuminance(a);
  final lb = _relativeLuminance(b);
  final lighter = math.max(la, lb);
  final darker = math.min(la, lb);
  return (lighter + 0.05) / (darker + 0.05);
}

double _relativeLuminance(Color color) {
  double channel(double c) => c <= 0.03928
      ? c / 12.92
      : math.pow((c + 0.055) / 1.055, 2.4).toDouble();
  return 0.2126 * channel(color.r) +
      0.7152 * channel(color.g) +
      0.0722 * channel(color.b);
}
```

```dart
import 'dart:ui' show FontFeature, FontVariation;

import 'package:material_ui/material_ui.dart';

/// Ojie's type scale (spec section 3.3). Styles have no color: the theme's
/// default text color applies, so they work in light and dark mode.
@immutable
class OjieTypography extends ThemeExtension<OjieTypography> {
  const OjieTypography({
    required this.display,
    required this.title,
    required this.heading,
    required this.numberXL,
    required this.body,
    required this.bodyStrong,
    required this.caption,
    required this.label,
    required this.button,
  });

  static const serifFamily = 'Fraunces';
  static const sansFamily = 'PlusJakartaSans';

  final TextStyle display;
  final TextStyle title;
  final TextStyle heading;
  final TextStyle numberXL;
  final TextStyle body;
  final TextStyle bodyStrong;
  final TextStyle caption;
  final TextStyle label;
  final TextStyle button;

  static final OjieTypography standard = OjieTypography(
    display: _serif(32, 38),
    title: _serif(24, 30),
    heading: _serif(19, 25),
    numberXL: _sans(40, 44, 800, letterSpacing: -1.2),
    body: _sans(15, 23, 400),
    bodyStrong: _sans(15, 23, 600),
    caption: _sans(13, 18, 500),
    label: _sans(11, 14, 700, letterSpacing: 0.77),
    button: _sans(15, 20, 700),
  );

  static TextStyle _serif(double size, double lineHeight) => TextStyle(
    fontFamily: serifFamily,
    fontSize: size,
    height: lineHeight / size,
    fontWeight: FontWeight.w600,
    letterSpacing: -0.01 * size,
    fontVariations: [
      const FontVariation('wght', 600),
      const FontVariation('SOFT', 100),
      FontVariation('opsz', size.clamp(9, 144).toDouble()),
    ],
  );

  static TextStyle _sans(
    double size,
    double lineHeight,
    int weight, {
    double letterSpacing = 0,
  }) => TextStyle(
    fontFamily: sansFamily,
    fontSize: size,
    height: lineHeight / size,
    fontWeight: FontWeight.values[(weight ~/ 100) - 1],
    letterSpacing: letterSpacing,
    fontVariations: [FontVariation('wght', weight.toDouble())],
    fontFeatures: const [FontFeature.tabularFigures()],
  );

  /// Maps Ojie's styles onto Material's text theme so default widgets
  /// (dialogs, snack bars, text fields) also use Ojie's fonts.
  TextTheme toTextTheme(Color text, Color text2) => TextTheme(
    displaySmall: display.copyWith(color: text),
    headlineSmall: title.copyWith(color: text),
    titleLarge: heading.copyWith(color: text),
    titleMedium: bodyStrong.copyWith(color: text),
    bodyLarge: body.copyWith(color: text),
    bodyMedium: body.copyWith(color: text),
    bodySmall: caption.copyWith(color: text2),
    labelLarge: button.copyWith(color: text),
    labelMedium: caption.copyWith(color: text2),
    labelSmall: label.copyWith(color: text2),
  );

  @override
  OjieTypography copyWith() => this;

  @override
  OjieTypography lerp(covariant OjieTypography? other, double t) =>
      other ?? this;
}
```

```dart
/// 4-point spacing scale (spec section 3.4).
abstract final class OjieSpace {
  static const double xs = 4;
  static const double sm = 8;
  static const double md = 12;
  static const double lg = 16;
  static const double xl = 24;
  static const double xxl = 32;
  static const double xxxl = 48;

  /// Left and right padding of every screen.
  static const double screen = 20;

  /// Gap between stacked cards.
  static const double cardGap = 12;
}

abstract final class OjieRadius {
  static const double chip = 8;
  static const double button = 14;
  static const double input = 14;
  static const double card = 22;
  static const double sheet = 28;
  static const double pill = 999;
}

abstract final class OjieSize {
  /// Smallest tappable size (Android accessibility guideline).
  static const double minTouch = 48;
}

abstract final class OjieMotion {
  static const press = Duration(milliseconds: 100);
  static const small = Duration(milliseconds: 200);
  static const screen = Duration(milliseconds: 300);
  static const curve = Curves.easeOutCubic;

  /// Returns [duration], or zero when the phone asks to reduce animations.
  static Duration of(BuildContext context, Duration duration) =>
      MediaQuery.maybeDisableAnimationsOf(context) ?? false
      ? Duration.zero
      : duration;
}
```

```dart
import 'package:material_ui/material_ui.dart';

import '../theme/ojie_tokens.dart';

enum OjieButtonVariant { primary, secondary, text }

/// Ojie's button. Styling comes from the theme; this adds the press scale,
/// the loading state and the optional leading icon.
class OjieButton extends StatefulWidget {
  const OjieButton({
    super.key,
    required this.label,
    required this.onPressed,
    this.variant = OjieButtonVariant.primary,
    this.icon,
    this.loading = false,
    this.expand = false,
  });

  final String label;
  final VoidCallback? onPressed;
  final OjieButtonVariant variant;
  final IconData? icon;
  final bool loading;
  final bool expand;

  @override
  State<OjieButton> createState() => _OjieButtonState();
}

class _OjieButtonState extends State<OjieButton> {
  bool _pressed = false;

  void _setPressed(bool value) {
    if (_pressed != value) setState(() => _pressed = value);
  }

  @override
  Widget build(BuildContext context) {
    final enabled = widget.onPressed != null;
    final child = widget.loading
        ? const SizedBox.square(
            dimension: 20,
            child: CircularProgressIndicator(strokeWidth: 2.4),
          )
        : Text(widget.label);

    final Widget button = switch (widget.variant) {
      OjieButtonVariant.primary when widget.icon != null => FilledButton.icon(
        onPressed: widget.onPressed,
        icon: Icon(widget.icon, size: 20),
        label: child,
      ),
      OjieButtonVariant.primary => FilledButton(
        onPressed: widget.onPressed,
        child: child,
      ),
      OjieButtonVariant.secondary when widget.icon != null =>
        OutlinedButton.icon(
          onPressed: widget.onPressed,
          icon: Icon(widget.icon, size: 20),
          label: child,
        ),
      OjieButtonVariant.secondary => OutlinedButton(
        onPressed: widget.onPressed,
        child: child,
      ),
      OjieButtonVariant.text when widget.icon != null => TextButton.icon(
        onPressed: widget.onPressed,
        icon: Icon(widget.icon, size: 20),
        label: child,
      ),
      OjieButtonVariant.text => TextButton(
        onPressed: widget.onPressed,
        child: child,
      ),
    };

    return Semantics(
      label: widget.loading ? widget.label : null,
      child: AbsorbPointer(
        absorbing: widget.loading,
        child: Listener(
          onPointerDown: enabled ? (_) => _setPressed(true) : null,
          onPointerUp: (_) => _setPressed(false),
          onPointerCancel: (_) => _setPressed(false),
          child: AnimatedScale(
            scale: _pressed ? 0.97 : 1,
            duration: OjieMotion.of(context, OjieMotion.press),
            curve: OjieMotion.curve,
            child: widget.expand
                ? SizedBox(width: double.infinity, child: button)
                : button,
          ),
        ),
      ),
    );
  }
}
```

```dart
enum SyncState { synced, pending, offline, error }

/// What the sync pill shows, decided from PowerSync's status and the number
/// of changes still waiting to upload.
class SyncSummary {
  const SyncSummary(this.state, this.pending);

  final SyncState state;
  final int pending;
}

SyncSummary summarizeSync({
  required bool connected,
  required int pending,
  Object? error,
}) {
  if (error != null) return SyncSummary(SyncState.error, pending);
  if (!connected) return SyncSummary(SyncState.offline, pending);
  if (pending > 0) return SyncSummary(SyncState.pending, pending);
  return const SyncSummary(SyncState.synced, 0);
}
```

```dart
import 'package:path/path.dart';
import 'package:path_provider/path_provider.dart';
import 'package:powersync/powersync.dart';
import 'package:supabase_flutter/supabase_flutter.dart';

import 'schema.dart';
import 'supabase_connector.dart';

/// Opens the phone's local database and keeps it connected to the signed-in
/// user's data. The UI always reads from here, so the app works offline.
Future<PowerSyncDatabase> openDatabase() async {
  final dir = await getApplicationSupportDirectory();
  final db = PowerSyncDatabase(schema: schema, path: join(dir.path, 'ojie.db'));
  await db.initialize();

  final auth = Supabase.instance.client.auth;
  if (auth.currentSession != null) {
    await db.connect(connector: SupabaseConnector());
  }

  // Start syncing on sign in. On sign out, wipe the local copy so the next
  // person on this phone never sees the previous user's data.
  auth.onAuthStateChange.listen((data) async {
    switch (data.event) {
      case AuthChangeEvent.signedIn:
        await db.connect(connector: SupabaseConnector());
      case AuthChangeEvent.signedOut:
        await db.disconnectAndClear();
      default:
        break;
    }
  });
  return db;
}
```

```dart
/// Sync pill state: PowerSync's connection status plus the upload queue size.
final syncSummaryProvider = StreamProvider<SyncSummary>((ref) async* {
  final db = ref.watch(powerSyncDatabaseProvider);
  var connected = db.currentStatus.connected;
  Object? error = db.currentStatus.anyError;
  var pending = (await db.getUploadQueueStats()).count;
  yield summarizeSync(connected: connected, pending: pending, error: error);
```
